# 라즈베리파이 5 에 올리기

맥에서 띄우던 것을 파이로 옮긴다. **맥은 그대로 두고** 파이가 자리를 잡은 뒤에
주소를 바꾸는 순서로 간다 — 말썽이 나면 되돌릴 데가 있어야 한다.

전제: 파이 5 · 16GB · SD 카드 · Raspberry Pi OS 64비트 · 두 달쯤 쓸 것

---

## 0. 순서를 왜 이렇게 잡나

```
1  Python · 의존성
2  PostgreSQL 17 설치 → DB 복원
3  환경변수
4  systemd 등록          ← 여기서 localhost 로 먼저 확인
5  cloudflared 터널      ← 그다음에 바깥으로 뺀다
6  관리자웹
7  Ollama                ← 없어도 나머지가 돌아야 한다
```

**터널을 먼저 붙이지 않는다.** 서버가 안 뜬 상태에서 바깥부터 뚫으면 서버 문제인지
터널 문제인지 안 갈린다. `curl localhost:8000` 이 먼저 되고 나서 뚫는다.

Ollama 를 마지막에 두는 것도 같은 이유다. 그게 없어도 목적지 매칭은 규칙 엔진으로
떨어져서 돌아간다(`llm→rule(사유)` 로 로그에 남는다).

## 1. 준비

### 64비트인지 확인

```bash
uname -m          # aarch64 여야 한다
free -h
lsblk
```

`armv7l` 이면 32비트라 Ollama 가 안 된다. OS 를 다시 깔아야 한다.

### 시간 동기화

**진행 판정이 시간을 잰다.** 추세 창(2초)·유지시간(3초)·정지 감시(30초)가 전부
시계 기준이라, 시계가 틀어지면 판정이 통째로 이상해진다.

```bash
timedatectl                       # System clock synchronized: yes
sudo timedatectl set-timezone Asia/Seoul
```

### SD 카드 쓰기 줄이기

두 달이면 버티지만 로그가 제일 많이 쓴다.

```bash
sudo mkdir -p /etc/systemd/journald.conf.d
printf '[Journal]\nSystemMaxUse=200M\nRuntimeMaxUse=64M\n' \
  | sudo tee /etc/systemd/journald.conf.d/limit.conf
sudo systemctl restart systemd-journald
```

비콘 로그는 5초마다 한 줄씩 쌓인다. 실측이 끝났으면 아래 4번에서 `LOG_BEACONS=0`
으로 꺼도 된다.

## 2. Python 과 의존성

```bash
sudo apt update

cd /opt
sudo git clone <저장소> wayfinder
```

`psycopg2-binary` 와 `Pillow` 는 aarch64 휠이 있어서 그냥 깔린다. 혹시 빌드로
넘어가면 위에 깐 `libpq-dev`·`build-essential` 이 받아준다.

## 3. PostgreSQL — **17 을 깔아야 한다**

Raspberry Pi OS 기본 저장소는 15 다. 그런데 맥에서 뜬 덤프는 17 이라
**15 에 넣으면 실패한다.** pg_dump 17 이 내는 `SET transaction_timeout` 같은 구문을
옛 서버가 모른다.

```bash
sudo apt install -y curl ca-certificates
sudo install -d /usr/share/postgresql-common/pgdg
sudo curl -o /usr/share/postgresql-common/pgdg/apt.postgresql.org.asc \
  https://www.postgresql.org/media/keys/ACCC4CF8.asc
echo "deb [signed-by=/usr/share/postgresql-common/pgdg/apt.postgresql.org.asc] \
http://apt.postgresql.org/pub/repos/apt $(lsb_release -cs)-pgdg main" \
  | sudo tee /etc/apt/sources.list.d/pgdg.list
sudo apt update
sudo apt install -y postgresql-17
```

### 계정과 DB

```bash
sudo -u postgres psql -c "CREATE ROLE wayfinder LOGIN PASSWORD 'wayfinder' SUPERUSER;"
sudo -u postgres psql -c "CREATE DATABASE wayfinder OWNER wayfinder;"
```

### 맥에서 떠서 옮기기

맥에서:

```bash
pg_dump -U wayfinder -d wayfinder -F c --no-owner --no-privileges \
  -f ~/Downloads/wayfinder.dump
scp ~/Downloads/wayfinder.dump pi@<파이주소>:~/
```

파이에서:

```bash
pg_restore -U wayfinder -d wayfinder --no-owner --no-privileges ~/wayfinder.dump
```

### 들어갔는지

```bash
psql -U wayfinder -d wayfinder -c "
SELECT (SELECT count(*) FROM beacons)          AS 비콘,
       (SELECT count(*) FROM landmarks)        AS 목적지,
       (SELECT count(*) FROM connectors)       AS 연결자,
       (SELECT count(*) FROM floor_path_nodes) AS 경로노드;"
```

**연결자가 0이면 층 이동이 안 만들어진다.** 그 상태로 넘어가면 안 된다.

## 4. 환경변수 — **`.env` 만으로는 부족하다**

이 프로젝트에는 `load_dotenv` 를 부르는 곳이 없다. `config.py` 의 pydantic 이
`.env` 를 읽지만 그건 거기 선언된 필드뿐이고, `os.environ` 에는 안 실린다.

```
.env 로 되는 것        DATABASE_URL · JWT_SECRET · JWT_EXPIRATION_MINUTES · CORS_ORIGINS
systemd 로 줘야 하는 것 LLM_* · LOG_BEACONS · BEACON_PICK · BEACON_MATCH_RADIUS_*
```

### `.env`

```bash
cat > /opt/wayfinder/.env <<'EOF'
DATABASE_URL=postgresql+psycopg2://wayfinder:wayfinder@localhost:5432/wayfinder
JWT_SECRET=<openssl rand -hex 32 로 만든 값>
JWT_EXPIRATION_MINUTES=1440
CORS_ORIGINS=https://<관리자웹주소>
EOF
chmod 600 /opt/wayfinder/.env
```

**`JWT_SECRET` 을 꼭 바꾼다.** 기본값이 `change-me` 라, 그대로 두면 공개 주소에서
관리자 토큰이 위조된다.

```bash
openssl rand -hex 32
```

## 5. systemd 등록

`/etc/systemd/system/wayfinder.service`

```ini
[Unit]
Description=WayFinder 안내 서버
# DB 가 뜬 뒤에 시작해야 한다. 먼저 뜨면 첫 연결이 실패한다.
After=network-online.target postgresql.service
Wants=network-online.target

[Service]
Type=simple
User=pi
WorkingDirectory=/opt/wayfinder
# .env 는 pydantic 이 WorkingDirectory 기준으로 읽는다.
# 아래 Environment= 는 os.environ 으로 들어가는 것들이다.
Environment=LLM_PROVIDER=ollama
Environment=LLM_MODEL=exaone3.5:2.4b
Environment=LLM_BASE_URL=http://localhost:11434
Environment=LLM_TIMEOUT=12
Environment=LOG_BEACONS=5
ExecStart=/opt/wayfinder/venv/bin/uvicorn app.main:app --host 127.0.0.1 --port 8000
Restart=always
RestartSec=3

[Install]
WantedBy=multi-user.target
```

`--host 127.0.0.1` 이다. **바깥에 직접 열지 않는다** — 터널이 대신 받는다.
포트를 열어두면 방화벽 없이 노출된다.

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now wayfinder
systemctl status wayfinder
journalctl -u wayfinder -f
```

### 여기서 먼저 확인한다

```bash
curl -s localhost:8000/api/buildings | head -c 200
```

건물 목록이 나오면 서버·DB·환경변수가 다 맞은 것이다. 여기까지 되고 나서
터널을 붙인다.

## 6. cloudflared 터널

```bash
curl -L -o cloudflared.deb \
  https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-linux-arm64.deb
sudo dpkg -i cloudflared.deb

cloudflared tunnel login
cloudflared tunnel create wayfinder-pi
```

`~/.cloudflared/config.yml`

```yaml
tunnel: <위에서 나온 터널 id>
credentials-file: /home/pi/.cloudflared/<터널id>.json

ingress:
  - hostname: <새주소>.mcsmtp.org
    service: http://localhost:8000
    originRequest:
      # 웹소켓이 오래 붙어 있는다. 기본 타임아웃에 끊기면 안내가 죽는다.
      noTLSVerify: false
      connectTimeout: 30s
  - service: http_status:404
```

```bash
cloudflared tunnel route dns wayfinder-pi <새주소>.mcsmtp.org
sudo cloudflared service install
sudo systemctl enable --now cloudflared
```

**맥 터널과 다른 주소를 쓴다.** 같은 주소를 두 곳에서 물면 요청이 아무 데나 가서,
어느 서버가 답했는지 알 수 없게 된다(실제로 그것 때문에 한참 헤맨 적이 있다).
파이가 확인되고 나서 주소를 바꿔 단다.

## 7. 관리자웹

지금은 따로 도는데, 파이 한 대면 서버가 같이 내주는 게 편하다.

```bash
cd WEB-FE
# .env 의 VITE_API_BASE_URL 을 https://<새주소>/api 로
npm run build          # dist/ 가 나온다
```

`dist/` 를 파이로 옮기고 `app/main.py` 끝에 붙인다.

```python
from fastapi.staticfiles import StaticFiles
app.mount("/", StaticFiles(directory="web", html=True), name="web")
```

**반드시 라우터 등록 뒤에 둔다.** 앞에 두면 `/api/...` 까지 정적 파일로 먹는다.

따로 두고 싶으면 안 해도 된다 — 그때는 `CORS_ORIGINS` 만 맞으면 된다.

## 8. Ollama

```bash
curl -fsSL https://ollama.com/install.sh | sh
ollama pull exaone3.5:2.4b
sudo systemctl enable --now ollama
```

### 모델을 작게 잡아야 하는 이유

파이 5 는 **GPU 가 없다.** Cortex-A76 4코어로 추론한다.

```
7.8b     1~2 토큰/초     답 하나에 20초 넘음. 못 쓴다
2.4b     4~6 토큰/초     5~10초
1.5b급   8~12 토큰/초    2~4초
```

RAM 16GB 라 7.8B 도 **올라가기는 한다.** 느려서 못 쓰는 것이지 메모리가 부족한 게
아니다. `LLM_TIMEOUT` 을 12초로 올려뒀는데, 2.4B 로도 자주 넘으면 더 작은 것으로
바꾸거나 아래 대안을 쓴다.

### 잘 안 되면

맥의 Ollama 를 가리킨다.

```
Environment=LLM_BASE_URL=http://<맥주소>:11434
```

맥이 꺼져 있으면 **알아서 규칙 엔진으로 떨어진다.** 방 번호와 정확한 이름은 그대로
되고 동의어("변소")만 안 된다. 아예 끄려면 `LLM_PROVIDER=off`.

### 디스코드 봇과 같이 돌 때

메모리는 16GB 라 여유롭다. 다만 **Ollama 가 돌 때 4코어를 다 먹는다.** 목적지를
말하는 순간에만 도니까 길어야 몇 초지만, 그동안 봇도 안내 판정도 밀린다.

신경 쓰이면 코어를 나눠준다.

```ini
# ollama.service 에
CPUQuota=200%          # 4코어 중 2개까지만
```

## 9. 앱 주소 바꾸기

`NavClient(serverUrl)` 에 넘기는 값을 새 주소로 바꾸고 다시 빌드한다.

```
wss://<새주소>.mcsmtp.org/ws/navigation
```

**`wss://` 여야 한다.** 안드로이드는 기본적으로 평문 `ws://` 를 막는다.
터널이 HTTPS 를 대신 해주므로 인증서를 따로 만들 일은 없다.

**이걸 꼭 해본다.** 배포의 핵심이 "꺼져도 다시 뜬다" 인데, 안 해보면 그게 되는지
모른다.

```bash
sudo reboot
# 2분 뒤
```
