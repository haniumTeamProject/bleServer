# 남아 있으나 쓰이지 않는 것

지우기 전에 기록만 해둔다. 문서·설계서에 "쓴다"고 적으면 안 되는 것들.

---

## 히스테리시스 (`rssi_filter._apply_hysteresis`)

```python
def filter(self, measurement):
    median_filtered = self._apply_median_filter(measurement)
    kalman_filtered = self._apply_kalman_filter(median_filtered)
    self._apply_hysteresis(kalman_filtered)     # self.state 만 갱신
    return kalman_filtered                       # 반환값에 반영되지 않음
```

`_apply_hysteresis` 는 `self.state`(DEPARTED / PRESENT / ARRIVED)를 갱신할 뿐이고
**반환값에는 영향을 주지 않는다.**

그 `state` 를 읽는 곳은 주석 처리된 출력 한 줄뿐이다.

```
app/ws/handler.py:1048
  #print(f"비콘 {key} | 원본: … | 필터: … | 상태: {pipeline.state.value}")
```

진행 판정(`path_tracker`)·층 판정(`_locate_floor`)·경로 생성 어디에서도 참조하지 않는다.
자바 시절 구조를 옮기면서 같이 넘어왔고, 그 뒤로 판정이 추세 비교로 바뀌면서
쓰이는 자리가 없어졌다.

### 그래서

```
실제 신호 정제    중앙값 3점 → 칼만       (2단)
히스테리시스      상태만 산출. 미사용
```

진입 -65dBm · 이탈 -75dBm 이라는 값도 그래서 지금은 아무 데도 안 쓰인다.

제작설계서에서는 히스테리시스 관련 항목을 전부 뺐다 (2단으로 정정).
코드에서 지우는 것은 아직 안 했다.
